## How to Deploy

To host this page on GitHub Pages:

1. Fork this repository to your own account.
2. Go to the **Settings** tab of your forked repository.
3. Navigate to the **Pages** section on the left sidebar.
4. Under **Build and deployment**, ensure the source is set to "Deploy from a branch".
5. Select the `master` (or `main`) branch and the `/root` folder.
6. Click **Save**.

Your site will be live at `https://<your-username>.github.io/<repository-name/>` within a few minutes.
